# Poly Lab 使用手册

## 启动和保存

1. 在项目目录运行 `npm ci`、`npm run build:studio`，然后运行 `npm start`。Windows 也可以用 `启动工作台.cmd` 打开已构建的工作台。
2. 打开 [本地工作台](http://127.0.0.1:8765/)。如果修改了服务端代码，在 Windows 可以运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/studio/restart.ps1`。使用 `npm start` 启动的终端可以先停止，再重新运行。
3. 使用固定浏览器和地址打开工作台。仓库和方案按浏览器配置与站点地址分别保存。重要方案用「导出 JSON」备份，模型可另存为 GLB。清除浏览器站点数据前先导出。

## 建立空间

在「空间重建」中新建空间。手动画房可以用矩形、墙线或模板建立户型，再在墙上添加门窗。用「参照 Scale」和一段实测墙长校准比例，并核对层高、门窗及家具尺寸。

选择视频建房时，先选择一段视频，打开「AI 自动建立房间」，按需调整抽帧数量或间隔。选定的关键帧会发送给配置的视觉模型，模型输出可编辑的墙体、门窗和家具。选「组合简模」可快速检查布局，选「精细网格」会对识别出的家具调用配置的图片转 3D 服务。模型估计的尺寸须用实测数据校准。

浏览器优先解码视频。遇到不支持的编码，可使用 H.264 MP4，或者安装 FFmpeg 并加入 PATH，也可以通过 `.env.local` 的 `STUDIO_FFMPEG_PATH` 指定可执行文件。效果图的 XLSX 附件需要本机 `python`，其余基本操作只需 Node.js 和浏览器。

## 录入和摆放家具

仓库初始有 MICKE 米克书桌、PS 2026 折叠椅和 RÅSHULT 拉舍推车。上传家具时可以选择同一件物品的不同角度照片，也可以从视频提取多帧。已有 GLB 文件可直接导入。完成后打开尺寸校准，按实测宽、深、高确认，再保存到仓库。

从空间画册打开或复制方案，将家具放入场景后调整位置、角度和底高。布局允许物件重叠和暂时放到房间外。落地、挂墙、顶装和自由搭配可在录入时选择。模型较重时可手动调低「显示质量」，需要检查细节时再切回。

## 配置混元家具生成

1. 打开首页「配置服务」，在「图片转 3D 模型」选择「混元 3D · 腾讯 TokenHub」，填写 TokenHub API Key。
2. 在 [TokenHub 在线推理服务](https://console.cloud.tencent.com/tokenhub/inference) 确认所选模型处于可用状态。免费额度耗尽后，需要为该模型启用后付费。充值余额、开通服务、启用后付费分别在控制台确认。
3. 录入时选择所需模型。极速版支持单张图片，3.1 或 3.0 专业版可选多视角。按当前任务的模型状态选择，已提交的任务会沿用原模型查询。

| 现象 | 处理方式 |
| --- | --- |
| `EACCES`、`ECONNRESET` 或连接超时 | 在录入框点「检查混元连接」。工作台会在生成前检查直连及已配置的代理路径。使用正常用户权限启动工作台，代理变化后重启服务。 |
| 402 计费拒绝 | 打开在线推理服务，核对所选模型的运行状态与后付费设置。确认 API Key 属于同一账户。 |
| 已生成，下载中断 | 点「恢复最近任务」并选择对应的时间和模型，继续下载原任务。仍在服务商有效期内的任务可恢复。 |
| 提交结果不明，没有返回任务编号 | 先到服务商核对任务和用量，再决定是否提交。 |
| GLB 很大 | 工作台边下载边写入本机磁盘，并检查文件是否完整。预览和入库所需内存取决于模型复杂度及浏览器环境。 |

默认优先检查混元直连，必要时使用 `HTTPS_PROXY` 或 `HTTP_PROXY` 中配置的代理。管理员可用 `.env.local` 的 `STUDIO_HUNYUAN_ROUTE=direct` 或 `proxy` 固定路径，默认值为 `auto`。修改后重启工作台。网络探测只发送无密钥的 HEAD 请求。生成请求发出后，工作台会返回原请求结果，由你核对任务状态。

## AI 布置和效果图

在「和 AI 一起设计」输入空间用途、家具取舍和动线要求。提案会列出对象操作，确认后点「应用到三维空间」。可用撤销回到原布局。

在「AI 效果渲染」中先调整人视或三维视角，再捕获当前视角，填写想要的风格和材质。生成后点击效果图放大，滚轮缩放，拖动查看，按 Esc 关闭。使用「保存效果图」下载图片。效果图中的装饰和比例可能与三维方案有差异，施工尺寸以实测和已确认的场景为准。
